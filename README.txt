BYAHERO CHIX RMS v0.2.0

FIRST WORKING BUILD

Included:
- Installable WordPress plugin
- Custom database tables for master data
- Dashboard
- Ingredient Categories
- Ingredients
- Suppliers
- Supplier Pricing + Preferred Supplier
- Preferred supplier base-unit cost calculation
- Units
- Settings
- Administrator + BC Manager capabilities
- Non-destructive uninstall

Not included yet:
- Workbook importer
- Recipes / Costing Engine
- Products / Menu
- Inventory Ledger / Purchasing
- POS / Payments / Kitchen
- Reports

Install on a DEVELOPMENT/STAGING WordPress site first:
Plugins > Add Plugin > Upload Plugin > choose ZIP > Activate.
